# 화면 피드백과 동작

`src/motion.css`는 버튼 눌림·호버, 작성창 포커스, 메시지 도구 모음, 대화상자·스레드·이모지 메뉴·알림의 등장 효과를 관리합니다. 주요 효과는 130–220ms이며 GPU 막대의 수치 전환은 350ms입니다. 닫기와 메시지 전송은 애니메이션 완료를 기다리지 않습니다. 추가 패키지는 없습니다.

`src/motion.ts`는 채널과 스레드의 로드 완료 시점에 마지막 메시지 ID를 기록합니다. 이후 더 큰 ID의 새 메시지만 등장 효과를 실행합니다. 최초 로드·이전 기록·수정·반응 갱신·채널 재방문은 메시지 등장 효과를 재생하지 않습니다. 한 갱신에서 마지막 6개까지만 애니메이션을 만들며 완료·취소 후 참조를 제거합니다. 메시지 수신·전송 방식과 서버 API는 바꾸지 않습니다.

전송 성공 응답을 받은 뒤 작성창에 1.8초 동안 `전송됨`을 표시하고 입력 포커스를 복구합니다. 실패하면 성공 표시 없이 기존 초안을 유지합니다. 전송 상태는 라이브 영역으로 제공하며 모바일과 스레드에서도 표시합니다.

운영체제의 동작 줄이기 설정은 CSS 효과와 JavaScript 메시지 효과 모두에 적용됩니다. 사용 중 설정을 바꾸면 진행 중인 메시지 효과도 취소합니다. 색상·텍스트 피드백은 유지합니다. 동작 구현은 [Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)와 [prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)을 사용합니다.

## 검증

격리된 브라우저 서버에서 메시지·스레드·반응·파일·검색·채널·DM·과거 기록·모바일·GPU·설치 파일 화면을 확인했습니다. 새 동작 시나리오는 등장 효과의 중복 방지, 채널 재방문, 전송 후 포커스, 동작 줄이기와 실행 중 설정 변경, 전송 실패 시 초안 보존을 확인합니다. 초기 11개 시나리오 중 10개가 통과했고, 계정 테스트의 상태 선택자를 해당 대화상자로 한정한 뒤 계정 및 동작 시나리오 3개를 재실행해 모두 통과했습니다. TypeScript 검사와 Vite 빌드도 통과했습니다.

운영 검증에서는 메시지를 보내지 않습니다. 공개 사이트의 대화상자 CSS 효과·동작 줄이기·모바일 메뉴·배포 HTML 일치를 확인합니다. Windows/macOS 패키지는 같은 웹 UI를 사용하지만 이번 변경에서 네이티브 설치 검증을 다시 실행하지 않았습니다.
